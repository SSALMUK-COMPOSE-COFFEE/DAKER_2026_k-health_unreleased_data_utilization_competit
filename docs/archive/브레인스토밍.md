## 0. 설명서를 읽고 바뀐 전제 3가지

### (1) 대전 20종 중 16종은 AI-Hub 공개 데이터 재배포다
진짜 미개방(건양대 자체 구축)은 **관상동맥석회화 / 위장내시경 / 신유량조절기 수액치료 / 안저** 4종뿐.
- 참신성 30점 관점에서 AI-Hub 데이터는 불리하다. "미개방 데이터 활용 대회"에서 이미 공개된 데이터를 고르는 셈.
- 반대로 실현성 30점 관점에서는 유리하다. **집에서 미리 받아 파이프라인을 검증**할 수 있어 폐쇄망 리스크가 사라진다.
- → 최적해는 **건양대 자체 구축 데이터를 고르되, 성격이 비슷한 AI-Hub 공개 데이터로 사전에 파이프라인을 검증**하는 하이브리드. 제안서에 "사전 검증 완료"를 쓸 수 있으면 실현성 점수가 확 올라간다.

### (2) 대구 OMOP CDM은 예선 단계에서 실체를 확인할 방법이 없다
샘플이 Synthea 합성데이터 5행짜리다. 본선에 심부전 환자 데이터가 온다지만 규모·품질을 모른 채 예선에서 데이터를 확정해야 하고, **본선에서 데이터 변경이 불가**하다. 리스크가 너무 크다 — 후순위.

### (3) 광주는 "지저분함" 자체가 문서에 명시된 스펙이다
5개 자치구가 테이블명·컬럼명·단위가 전부 다르고, 결측·이상값·음수값이 있다고 카탈로그가 대놓고 적어놨다. 정제 부담이 크지만, 뒤집으면 **데이터 하모나이제이션 방법론을 결과물로 팔 수 있다**는 뜻이다.

## 1. 추천 아이디어

### ⭐⭐ 1순위 — [대전] 저선량 흉부CT 기회주의적 심혈관 위험 스크리닝
**데이터셋: 2D 검진이미지(관상동맥석회화) — 건양대 자체 구축, 진짜 미개방**

**아이디어**
이 데이터는 같은 환자의 **Cardiac CT(3개월 이내) + non-contrast 흉부CT가 페어로 묶여** 있다. Cardiac CT에서 나온 CACS(관상동맥 석회화 지수)를 정답지로 두고, **폐암 검진용으로 이미 찍고 있는 저선량 흉부CT만으로 심혈관 위험도를 추정**할 수 있는지 검증한다. 즉 "검사를 한 번 더 하지 않고, 이미 찍은 영상에서 공짜로 심장 위험을 건진다".

산출물은 ① CACS 등급별 흉부CT 영상 특징 정량화·시각화, ② 흉부CT → CACS 등급 추정 모델, ③ 검진 리포트에 바로 붙일 수 있는 심혈관 위험 알림 UI 시안.

**평가기준 적합도**
- 시의성 ◎ — 국가 폐암검진 사업(만 54~74세 고위험군)이 매년 수십만 건의 저선량 흉부CT를 찍고 있는데, 심장은 보고도 안 본다. 심혈관질환은 국내 사망원인 2위.
- 실현성 ○ — 320명은 딥러닝에 적은 편이지만 슬라이스 단위로는 충분하고, **라디오믹스 특징 + 그래디언트 부스팅** 같은 CPU 친화 방법으로도 완결된 분석이 나온다. 안심존에 GPU가 없어도 망하지 않는 설계가 가능한 게 핵심.
- 참신성 ◎ — 진짜 미개방 데이터 + 페어 구조를 활용한 opportunistic screening. 이런 페어 데이터셋은 국내에 거의 없다.
- 파급성 ◎ — 국가검진 체계에 그대로 얹을 수 있고, 추가 비용·추가 피폭이 0이라는 논리가 강력하다.

**리스크와 대응**
- CT DICOM 3D 처리 부담 → pydicom/SimpleITK/pyradiomics 반입 신청 필요. 대전 안심존은 **패키지 반입 신청이 가능**한 유일한 곳이라는 게 이 선택의 결정적 이점.
- 320명은 적다 → 슬라이스/혈관 분절 단위 분석 + 교차검증으로 보완. 애초에 "예측 성능 대회"가 아니라 시각화 보고서이므로 치명적이지 않다.
- 사전 프로토타입 불가(미개방) → 공개 CT 데이터(LIDC-IDRI 등)로 파이프라인만 미리 짜두고 안심존에서는 실행만 한다.

### ⭐ 2순위 — [대구] 원내 심정지 전 활력징후 악화 궤적 시각화
**데이터셋: 경북대병원 입원환자 Vital Sign**

**아이디어**
`CARDT`(심정지 발생 일시, 분 단위)를 시점 0으로 정렬해 **심정지 직전 24~72시간의 활력징후 궤적**을 그린다. 기존 조기경보점수(NEWS/MEWS)를 이 573명에 소급 적용해 "언제 경보가 울렸어야 했는데 울리지 않았는가"라는 **경보 공백(missed window)을 시각화**하고, 악화 유형을 군집화(급격 악화형 / 서서히 악화형 / 무증상형)한다.

**평가기준 적합도**
- 시의성 ◎ — 신속대응팀(RRT) 확대와 환자안전 정책의 핵심 주제. 데이터도 2023~2025년으로 가장 최신.
- 실현성 ◎ — 테이블 2개, 컬럼 12개, 순수 수치 시계열. R이든 Python이든 기본 패키지로 끝난다. **폐쇄망 리스크가 사실상 0**인 유일한 데이터셋.
- 참신성 ○ — EWS 자체는 기존 개념이지만, 사망 사례를 역산해 경보 공백을 드러내는 프레이밍은 충분히 신선하다.
- 파급성 ◎ — 병원 EMR 경보 임계값 조정, 야간 간호 인력 배치 근거로 바로 연결된다.

**리스크와 대응**
- **사망군만 있고 생존 대조군이 없다.** 따라서 "예측 모델"로 프레이밍하면 평가가 불가능해 심사에서 깨진다. 반드시 **패턴 발굴 + 경보 공백 진단**으로 프레이밍할 것. 이건 리스크가 아니라 제안서 설계의 문제다.
- 573명 × 가변 측정 주기 → 결측 처리 규칙이 문서에 없다. 안심존 방문해서 실제 밀도를 봐야 한다.
- 일자가 shift 처리되어 있어 계절성·요일 분석은 불가. 상대 시간 간격 분석만 가능.

### ⭐ 3순위(다크호스) — [대전] 항암 수액 주입 오차의 결정 요인 분석
**데이터셋: 신유량조절기 수액치료 — 건양대 자체 구축**

**아이디어**
환자 100명, 120회 실험이 **수액높이(2)·주입속도(4)·수액종류(2)를 인자로 하는 8개 실험군**으로 짜여 있고,
(⚠️ 2×4×2 = 16이므로 완전 교차가 아니다 — [원문검증 발견 6](memory/05-데이터-설명서-원문검증.md)에서 정정) 처방속도 대비 실제 유량·오차·절대오차가 그대로 컬럼에 있다. 어떤 조건에서 항암제가 처방보다 빠르거나 느리게 들어가는지를 정량화하고, **조건별 오차 지도(nomogram)와 간호 현장용 수액 높이·속도 권고표**를 만든다.

**평가기준 적합도**
- 시의성 ○ — 항암제 주입 속도 오차는 부작용과 직결되는 환자안전 이슈다.
- 실현성 ◎◎ — 표 하나. 어떤 환경에서도 100% 완주 가능.
- 참신성 ◎ — 아무도 다루지 않았을 주제이고, 진짜 미개방 데이터다.
- 파급성 ○ — 전국 항암주사실 프로토콜로 확장 가능하지만 임팩트 규모는 위 둘보다 작다.

**리스크**: 120행은 본선 "우수성 20점"에서 빈약해 보일 수 있다. **단독으로 밀기보다, 1순위가 안심존 방문 후 무너졌을 때의 백업안**으로 두거나, 다른 아이디어의 보조 분석으로 붙이는 게 낫다.

## 2. 지역 선택에 대한 판단

대전이 가장 가깝고 다른 지역도 월차로 갈 수 있다면, **대전으로 확정하는 게 맞다.**

근거:
1. **본선 수행평가 30점 중 10점이 방문 횟수**다. 7회 이상이어야 만점인데, 평일 08:30~17:30만 운영한다. 월차 7번은 비현실적이므로 접근성이 곧 점수다.
2. **대전 안심존만 패키지 반입 신청이 가능**하다. 대구·광주는 본선 전에 사용할 패키지 목록을 미리 확정해 제출해야 하는데, 분석하다 보면 필요한 라이브러리는 반드시 바뀐다. 이건 생각보다 큰 차이다.
3. **예선 기간에 대전 안심존 한 곳에서 대구·광주 샘플까지 전부 볼 수 있다.** 즉 대전 방문 한 번으로 가점 5점을 챙기면서 세 지역 데이터를 모두 실사할 수 있다.

다만 2순위(대구 활력징후)의 데이터 단순함과 스토리 강도가 상당하므로, **예선 방문 때 대전 CAC와 대구 활력징후 샘플을 나란히 보고 최종 결정**하는 게 가장 안전하다.
