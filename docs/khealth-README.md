## 데이터셋 선택 근거

**[대구] 경북대학교병원 입원환자 활력징후(Vital Sign) 데이터**로 확정했다.

세 가지가 결정적이었다.

1. **진성 미개방.** 대전 건양대 20종 중 15종은 이미 AI-Hub에 공개된 데이터의 안심존
   제한 재배포이고, 설명서에 원본 URL이 그대로 적혀 있다. 건양대 자체 구축 5종은 가장
   얇으며, 그중 안저 데이터는 이미 식약처 3등급 품목허가 제품(아이뷰)이 나와 신규성 주장이
   어렵다. 조사 결과는 이 문서 하단 참조.
2. **결과가 분 단위로 확정.** 573명 전원 사망, `CARDT`·`DEATHDT`가 분 단위. 다른 데이터의
   판독 라벨과 달리 라벨 잡음이 없다.
3. **폐쇄망 적합.** 표 2개·수치 6종이라 GPU도 사전학습 가중치도 필요 없다. 인터넷 차단과
   패키지 자동 설치 불가라는 규칙이 영상 딥러닝 제안에는 실질적 위험인데, 여기서는 거의
   영향이 없다.

## 제안 요지

심정지를 원점으로 시간을 거꾸로 읽어 환자마다 세 시점을 추정한다.
**T_phys**(생리 이탈) · **T_rule**(규칙 발화) · **T_obs**(관측 강화).
세 번째가 핵심 — `VSDT`의 **측정 간격 자체를 임상 판단의 흔적으로 읽는다.**
간격이 짧아지는 것은 사람이 걱정하기 시작했다는 뜻이며, 추가 데이터가 필요 없다.

두 격차가 산출물이다. 탐지 격차(T_phys − T_rule)는 임계값 문제를, 인지 격차
(T_phys − T_obs)는 구심로 실패를 가리킨다.

**예측 모델을 만들지 않는다.** 573명 전원이 사례라 음성 표본이 0명이고, 특이도·양성예측도·
오경보율은 원리상 계산이 불가능하다. 계산할 수 없는 것을 보고하지 않는다는 선언을 §2.3에
표로 박아 두었다. 검증은 사례교차(자기대조)로 한다.
