## ★ 발견 1 — 설명서가 이미 "오차율 평균 ±10% 이내"라고 밝혔다

7페이지 원문:

> "초기 분석 결과, **오차율(% error)의 평균값은 설정된 치료 시간 대비 ±10% 이내**로
> 확인되었으며, 부작용 발생률은 연구 제외 기준을 적용하여 최소화하였습니다."

**이건 위협이자 기회다.**

위협: "오차가 크다"를 전제로 한 제안은 설명서 자체와 충돌한다. 심사위원이 설명서를
읽었다면 즉시 걸린다. [아이디어 골격](04-아이디어-골격.md)의 H2 중심 프레이밍을
"오차가 크다"로 쓰면 안 된다.

기회: 평균이 ±10%라는 사실은 **질문을 평균에서 조건부·꼬리로 밀어낸다.**
그리고 결정적으로, 설명서는 오차가 **작다**고 했을 뿐 그 오차가 **약물별로 임상적으로
허용되는지는 말하지 않았다.** 120분 주입의 ±10%는 ±12분이다. 어떤 항암제에는
무해하고 어떤 항암제에는 허가사항 용법을 벗어난다. **그 판정이 우리 몫이고, 그게
RAG 층의 존재 이유다.**

→ 프레이밍 확정: **"평균 ±10%는 안전한가"**. 오차의 크기가 아니라 오차의 **허용 여부**를 다툰다.

## ★ 발견 2 — 약물명 표기가 심하게 오염되어 있다 (RAG 층의 진짜 정당화)

4~5페이지의 항암제 값 목록을 원문 그대로 옮기면:

```
BevaciZumab / Bevacizumb / Carboplatin / Cetuximab / Cisplain / Cisplatin /
Cisplatine / Gemcitabin / Gemcitabine / Irinotecan / Leucovorin / Leucovorin sod /
Nivolumab / Nivolumab 옵디보주 / Oxailplatin / Oxaliplati / Oxaliplatin /
pembrolizumab / Pembrolizumb / Perbrolizumab / Ramucirumab / Trastuzumab-Deruxt
```

**22개 문자열이 실제로는 12개 성분이다.**

| 실제 성분 | 데이터상 표기 | 문제 |
|---|---|---|
| Bevacizumab | BevaciZumab, Bevacizumb | 대문자 오류 + 철자 누락 |
| Cisplatin | Cisplain, Cisplatin, Cisplatine | 철자 오류 2종 |
| Gemcitabine | Gemcitabin, Gemcitabine | 철자 누락 |
| Oxaliplatin | Oxailplatin, Oxaliplati, Oxaliplatin | 철자 오류 2종 |
| Pembrolizumab | pembrolizumab, Pembrolizumb, **Perbrolizumab** | 대소문자 + 철자 누락 + **자음 오류** |
| Nivolumab | Nivolumab, Nivolumab 옵디보주 | 상품명 혼입 |
| Leucovorin | Leucovorin, Leucovorin sod | 염 표기 혼입 |
| Trastuzumab deruxtecan | Trastuzumab-Deruxt | 절단 |

진단명도 같은 문제다: `cholangiocarcinoma` / `cholangiocarcinoma, intrahepatic` /
`cholangiocellular carcinoma`, `gastric cancer` / `gastric cancer NOS, unspecified`,
`pancreatic cancer` / `pancreatic cancer, tail` / `malignant neoplasm of pancreas, unspecified`,
그리고 `gallbblader cancer`(gallbladder 오타).

수액 종류도 2수준 요인인데 문자열이 3개다: `N/S(0.9%)`, `멸균생리식염수`, `5% DW`.

**이게 제안서에서 가장 강한 카드다.** `Perbrolizumab`으로는 어떤 의약품 데이터베이스도
조회되지 않는다. 즉 **이 데이터를 약물 근거 문서에 연결하려면 의미 기반 정규화가
반드시 선행되어야 한다.** LLM/RAG를 장식으로 붙이는 게 아니라, 정규화 없이는 분석
자체가 불가능하다는 구조적 필요다. 심사위원이 "왜 LLM을 쓰나"라고 물을 때의 답이 여기 있다.

그리고 규모가 유리하다. 22개 문자열 → 12개 성분은 **전수 수작업 검증이 가능한 크기**다.
LLM 정규화 결과를 100% 사람이 확인해서 정확도를 보고할 수 있다. 환각 리스크를
제안서에서 정면으로 닫을 수 있는 드문 조건.

## ★ 발견 3 — 부작용 데이터는 함정이다. 절대 설계에 넣지 말 것

설명서 서술부는 부작용을 세 번 언급한다.

- 3페이지: "오차율(% error)과 **부작용 발생 여부**를 측정하고"
- 3페이지: "오차율과 **부작용 발생률**을 분석함으로써"
- 6페이지: "주입 속도, 오차율, **부작용 발생 여부** 등이 기록됩니다"

그런데 **4~5페이지의 데이터 포맷 23개 컬럼에 부작용 컬럼이 없다.** 그리고 7페이지는
"부작용 발생률은 연구 제외 기준을 적용하여 **최소화**하였습니다"라고 적었다.
제외기준 (4)가 "하루 1L 이상 생리식염수 주입 시 부작용이 예상되는 환자"를 배제한다.

→ 부작용은 **컬럼으로 존재하지 않거나, 존재해도 사실상 전부 0**이다.
"오차 → 부작용 연관 분석"을 제안하면 본선에서 데이터를 열었을 때 무너진다.
서술만 읽고 설계했으면 걸렸을 함정. **오차의 임상적 의미는 부작용 실측이 아니라
약물 근거 문서(RAG)로 판정해야 한다** — 이 발견이 RAG 방향을 다시 한 번 정당화한다.

## 발견 4 — between-subject 설계다 (교란 가능성)

6페이지: "환자는 수액 높이, 주입 속도, 수액 종류에 따라 **8개의 실험군 중 하나에 배정**되고"

환자 내 반복이 아니라 군간 배정이다. 따라서 8군 비교는 환자·약물·암종 구성 차이에
교란될 수 있다. 무작위 배정 여부는 설명서에 없다.

→ 분석 설계에 **군간 공변량 균형 확인(성별·연령·약물·수액 총량)을 1단계로 명시**하고,
불균형 시 보정 모형을 쓴다고 써야 한다. 이걸 먼저 짚는 것 자체가 실현성 점수에서 유리하다.
120명이 아니라 환자 100명 / 실험 120회이므로 일부 환자는 반복 측정이 있다 →
군내 환자 중복 여부도 확인 대상.

## ★ 발견 6 — 완전요인설계가 아니다 (2026-07-31 재판독)

**설명서 원문 세 곳을 다시 렌더링해 확인했다.**

| 페이지 | 원문 |
|---|---|
| 3 (개요) | "연구는 **8개의 실험군**으로 설계되었으며, **총 120회**의 실험 데이터를 수집하였습니다." |
| 6 (수집 절차) | "환자는 수액 높이, 주입 속도, 수액 종류에 따라 **8개의 실험군 중 하나에 배정**되고" |
| 7 (데이터 통계) | "연구 설계에 따라 **8개의 실험군**으로 나뉘어 수집되었습니다. 실험군별로 수액 높이(150cm, 200cm), 주입 속도(30분, 60분, 90분, 120분), 수액 종류(NS, 5% D/W)와 같은 다양한 조건에서" |

**2 × 4 × 2 = 16인데 실험군은 8개다. 완전 교차 설계가 아니다.**

- 설명서 어디에도 **"완전요인"이라는 단어가 없다.** 우리가 붙인 말이었다
- **"군당 15회"도 설명서에 없다.** 120÷8 = 15는 우리 역산이며, 표1에는 군별 인원이 없다
- **어떤 8개 조합인지 기재가 없다.** 유력 구조는 높이(2) × 주입시간(4) = 8이고 수액종류
  미교차 — 실제 항암에서는 약제가 희석액을 결정하므로 독립 배정이 어렵다

### 제안서에 미친 영향 (수정 완료)

| 폐기한 표현 | 대체 |
|---|---|
| "완전요인설계 8군" | "8개 실험군 · 총 120회" + 미기재 항목 명시 |
| **"3요인 교호작용을 추정하는 유일한 설계"** | "**높이를 실험 인자로 조작하고 주입시간과 교차시킨** 유일한 실환자 설계" |
| "군당 15회의 설계된 반복" | "군당 평균 15회" (추정임을 표기) |
| "8군 설계와 23컬럼이 전부 명시" | 미기재 항목을 목록화하고 방문 1단계 확인으로 고정 |

**손실은 크지 않다.** 높이 × 주입시간 2차 교호작용은 어떤 구성에서도 추정 가능하고,
그 축이 정확히 [정수압 모형](09-정수압모형-사전예측.md)이 예측하는 축이다. 수액종류는
MDER 2025가 이미 무의미로 판정해 부차 인자로 내려둔 상태였다. **P2(수액 총량)는 설계
인자가 아니라 관측 공변량이므로 영향이 없다** — 가장 강한 카드는 그대로다.

→ **방문 1단계 최우선 작업 = 8군의 인자 조합을 교차표로 복원.** 모형이 여기서 갈린다.

## 발견 7 — 7페이지 내부에 성별 수치 불일치

| 위치 | 값 |
|---|---|
| 7페이지 본문 | "성별 분포는 **남성 60%, 여성 40%**" |
| 7페이지 표1 | **남 74 / 여 26** (총합 100) |

같은 페이지에서 어긋난다. 환자 100명 기준과 실험 120회 기준(120의 60/40 = 72/48)이
혼재했을 가능성이 있으나 설명서만으로는 확정 불가.

→ **표1 값만 채택하고 서술부 수치는 인용하지 않는다.** 발견 3(부작용)과 같은 패턴이며,
**"명세를 채택하고 서술부를 채택하지 않는다"**는 원칙이 또 한 번 확인됐다.

## 골격에 반영할 것

1. 프레이밍을 "오차가 크다" → **"평균 ±10%는 약물별로 허용되는가"**로 교체
