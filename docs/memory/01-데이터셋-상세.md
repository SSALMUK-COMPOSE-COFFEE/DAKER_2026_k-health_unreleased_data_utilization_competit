### 이게 왜 중요한가 (양날의 검)
- **참신성(30점) 관점**: AI-Hub 데이터는 이미 공개되어 수많은 팀이 다뤄본 것. "미개방 데이터 활용"이라는 대회 취지에서 심사위원이 감점 요인으로 볼 수 있음. 건양대 자체 구축 4종은 아무도 손대지 않은 진짜 미개방 데이터.
- **실현성(30점) 관점**: ~~반대로 AI-Hub 데이터는 집에서 미리 받아 프로토타입을 돌려볼 수 있다~~ → **❌ 이 전제는 틀렸다 (2026-07-30 확인)**. 아래 참조.
- **결론**: 건양대 자체 구축 데이터를 고르되, **해외 자유 다운로드 공개 데이터**로 사전에 파이프라인을 검증하는 하이브리드 전략이 최적.

### ❌ 정정 — AI-Hub 의료데이터는 자유 다운로드가 안 된다 (2026-07-30 확인)

"AI-Hub 재배포니까 집에서 미리 받아 검증할 수 있다"는 전제를 실제로 확인해보니 **성립하지 않는다.**

| 확인한 데이터셋 | 제공 방식 |
|---|---|
| 태아 심박동 모니터링 (`dataSetSn=71366`) | **온라인 안심존 전용, 일반 다운로드 불가** |
| 무릎 관절염 K-L grade (`dataSetSn=71664`) | **온라인 안심존 전용, 일반 다운로드 불가** |

AI-Hub 보건의료 데이터는 대체로 안심존 전용이고, **안심존 사용신청에 IRB 심의 결과 통지서 + IRB 승인 연구계획서 + 소속 증명이 필요하다.** 개인·직장인 참가자에게는 사실상 닫힌 경로다.
문의: safezone1@aihub.kr / 02-525-7708, 7709 · 안심존 포털 https://safezone.aihub.or.kr/

**단, 역설적 반전**: AI-Hub **온라인** 안심존은 "집·연구실·사무실 어디서나 접속"이 가능하다. 즉 원격이 되는 쪽은 AI-Hub이고, 건양대 안심존은 오프라인 방문 전용이다. IRB만 통과하면 AI-Hub 쪽은 재택 분석이 되지만, 대회 제출물은 건양대 안심존 데이터로 만들어야 하므로 대회 완주에는 도움이 되지 않는다.

→ **사전 검증에 쓸 수 있는 건 국내 AI-Hub가 아니라 해외 자유 다운로드 공개 데이터다** (Stanford AIMI COCA, PhysioNet CTU-UHB CTG, Kvasir/HyperKvasir, OAI, EyePACS/APTOS 등).

## [대전] 건양대 자체 구축 4종 (핵심)

### ★ 관상동맥석회화 — 2D 검진이미지
- **구조**: Cardiac CT를 찍은 환자 중 **3개월 이내에 non-contrast chest CT(저선량 포함)도 찍은 환자**의 페어 영상. `K-0001/A1-0001(Cardiac)`, `B1-0001(Chest)` 폴더 구조, `.dcm` + `.json`
- **규모**: 320명 (남 206 / 여 114). 연령: 60대 101, 70대 102, 50대 32, 80대 61, 40대 15, 30대 4, 90대 4, 20대 1
- **라벨**: **CACS(Coronary Artery Calcium Score)** 관상동맥 석회화 지수 + 석회화 유무/중증도 등급(1·2·3·4) + 나이·성별·검사일자·검사명. XML 또는 JSON
- **설계 의도**: 석회화 있음 225 case + 정상 75 case 목표, 1~4등급 유사 비율 권고
- **수집 기간**: 2018-01 ~ 2023-06
- **제외**: 스텐트 시술, 관상동맥우회술(CABG), 인공물(artifact) 심한 경우
- **툴**: `labelme_dicom` 폴더에 default_config.yaml + Labelme.exe 동봉
- **주목 포인트**: Cardiac CT(정답지)와 Chest CT(입력)가 **환자 단위로 페어링된 데이터는 매우 희귀**. 기회주의적(opportunistic) 스크리닝 연구에 완벽한 구조.

### ★ 위장(대장)내시경
- **규모**: 15,676장 JPG — Normal 8,548(54.5%) / Polyp 7,128(45.5%). **클래스 균형 우수**
- 2015-01 ~ 2020-12 건양대병원 snapshot 이미지, 익명화 완료, 화질 저하 이미지 제외
- 라벨: 이진 분류(파일명/메타데이터). 바운딩박스·마스크 언급 없음
- 평가: 실현성 최고 / 참신성 최저(폴립 분류는 레드오션)

### ★ 신유량조절기 수액치료 (다크호스)
- **규모**: 환자 100명(남 74/여 26, 40대 17·50대 10·60대 52·70대 20), **총 120회 실험**. 표 형태 데이터
- **설계**: 8개 실험군, 총 120회. 인자는 수액높이(150·200cm) × 주입속도(30·60·90·120분) × 수액종류(NS·5% D/W)
  ⚠️ 2×4×2 = 16인데 군은 8개 → **완전 교차 아님. 군별 반복수 미기재**(15는 역산치)
  ([원문검증 발견 6](05-데이터-설명서-원문검증.md))
- **컬럼 23개**: 날짜(2023.11.29~12.15), 성별, 나이, 진단명(암종 20여 종), 항암제(20여 종), 농도, 항암제 총량, 수액 총량, 수액종류, **처방속도(ml/h), 처방용량, 주입시작/종료시간, 실제 주입량, 이론 주입시간, 실제 주입시간, 실제 유량, 오차, ABS(절대오차)**
- **대상**: 만 19세 이상 항암치료 환자, 서면동의. 제외: 18세 미만/80세 이상, Cr>2.0, 고나트륨혈증 등
- **평가**: 규모는 작지만 **통제된 실험 설계**라 통계 분석이 깔끔. 참신성 매우 높음(아무도 안 다뤘을 주제), 실현성 최고. 다만 본선 "우수성 20점"에서 데이터 규모가 약점

## [대구]

### 경북대병원 입원환자 활력징후 ★
- **대상**: 2023~2025년 입원 중 **심정지 발생 20세 이상 환자 573명** (남 376 / 여 197). 60대 132, 70대 149, 80대 146명
- **제외**: 20세 미만·90세 이상, **입원 후 24시간 이내 심정지**
- **KHTH_PINFO**: PATID, AGE(10년 단위 범주화), SEX, INDD(입원일), OUDD(퇴원일), **CARDT(심정지발생일시 YYYYMMDDHHMI)**, DEATHDT(사망일시)
- **KHTH_VITAL** (long format): PATID, INDD, VSDT(기록일시 분단위), VS_GBN(HR/SBP/DBP/BT/SPO2/RR), VS_RSLT
- **측정 주기**: 예시 기준 약 10분 간격이나 환자 상태에 따라 가변
- **비식별화**: 환자번호 대체, 연령 범주화, **일자 shift 처리** (→ 절대 날짜는 못 쓰지만 상대 시간 간격은 보존)
- 결측 처리 규칙은 문서에 미기재. 샘플은 5명분
- **핵심**: `CARDT`가 분 단위로 있어서 **심정지 시점 정렬(time-to-event alignment) 분석이 바로 가능**
