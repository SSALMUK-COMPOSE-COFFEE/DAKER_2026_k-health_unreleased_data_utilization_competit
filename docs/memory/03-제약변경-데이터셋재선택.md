# 제약 변경에 따른 데이터셋 재선택 (2026-07-30)

> 사용자 결정 두 가지가 들어왔고, 그 결과 1순위 데이터셋이 바뀐다.
> 이전 판단: [브레인스토밍](../archive/브레인스토밍.md) · [CAC 제안서 초안](../archive/제안서-초안.md) → **폐기**

## 들어온 제약

| 항목 | 이전 가정 | 확정된 사실 |
|---|---|---|
| 예선 안심존 방문 | 8월 첫 주 1회 (가점 +5) | **가지 않음** |
| 본선 안심존 방문 | 3회 (수행평가 6점) | **월차 1회** (수행평가 2점) |
| 기술 방향 | 라디오믹스 + 그래디언트 부스팅 | **딥러닝 직접 구축 없음, RAG 형식** |

## 이 제약이 바꾸는 것 세 가지

### (1) 예선 미방문 → 데이터 실물을 영원히 못 보고 제안서를 쓴다

샘플 데이터는 안심존에서만 열람 가능하고 다운로드 제공이 없다. AI-Hub 우회 경로도
IRB 심의 결과 통지서가 필요해서 막혀 있다([데이터셋 상세](01-데이터셋-상세.md) 22~34행).

결론: **데이터 설명서에 명시되지 않은 사실은 제안서에서 주장할 수 없다.** 그리고
리스크 대응란에 "방문해서 확인하겠다"를 쓸 수 없다. 심사위원이 실현성 30점을 볼 때
"이 팀은 데이터를 못 본 상태인데 계획이 성립하나"를 검증하게 되므로,
**설명서만으로 스펙이 완결된 데이터셋**이 절대적으로 유리해진다.

이 기준으로 대전 자체구축 4종을 다시 보면:

| 데이터셋 | 설명서 기준 스펙 확정도 | 판정 |
|---|---|---|
| 관상동맥석회화 | 등급 분포가 "석회화 225 + 정상 75 **목표**"이고 실인원 아님. CACS 산출 원본이 조영증강 Cardiac Angio CT인지 불명 | **불확실성 최대** |
| 위장(대장)내시경 | 15,676장, Normal 8,548 / Polyp 7,128 명시 | 확정 |
| **신유량조절기** | **8군 · 120회, 23컬럼 전부 명시, 오차·절대오차가 이미 컬럼으로 존재** (군별 조합·반복수는 미기재 — [발견 6](05-데이터-설명서-원문검증.md)) | **거의 완결** |
| 안저 | 화각별 진단별 장수 전부 명시 | 확정 |

CAC 제안서는 리스크 대응 전략 자체가 "예선 방문에서 실측"에 걸려 있었다
([제안서-초안](../archive/제안서-초안.md) 172행, 277~282행). 그 전제가 사라지면 설계가 무너진다.

### (2) 본선 방문 1회 → 하루 안에 완주 가능한 규모만 살아남는다

대전 안심존은 평일 18:00 마감, 오프라인 방문 전용, 관저동 소재다. 월차 하루로
아침 출발 시 실질 체류 6~7시간, 점심과 환경 셋업·경로 디버깅을 빼면 **순수 분석 4시간
내외**다. 처음 보는 데이터에서. 그리고 그 세션 안에 결과물 반출 신청까지 끝내야 한다
(심의 1~2주, 11/6 마감 역산).

| 데이터셋 | 4시간 완주 가능성 |
|---|---|
| 관상동맥석회화 CT | **불가.** 환자당 Cardiac+Chest 2시리즈 × 수백 슬라이스 = 수십만 슬라이스. 로딩만으로 세션이 끝난다 |
| 위장내시경 15,676 JPG | 위험. CPU 특징추출은 되지만 학습·검증까지는 무리 |
| 안저 5,400 JPG | 위험. 동일 |
| **신유량조절기 120행 × 23컬럼** | **여유. 실행 수 초, 재분석 반복 가능** |

방문 1회 제약은 CAC를 후보에서 탈락시킨다. 이건 선호가 아니라 산술이다.

### (3) RAG 방향 → 이미지 데이터셋과 애초에 결이 맞지 않는다

RAG는 문서 검색 기반 생성이다. 표 형태 데이터에서 나온 수치·규칙에
근거 문서를 붙이는 구조가 자연스럽고, 영상 분류와는 접점이 약하다.

그리고 결정적으로, **RAG 레이어가 신유량조절기의 유일한 약점(120행 규모)을 정확히 메운다.**
이전 판단에서 이 데이터셋을 3순위로 내린 근거가 "120행은 본선 우수성 20점에서 빈약해
보인다"였다([브레인스토밍](../archive/브레인스토밍.md) 80행). RAG 시스템이 산출물의 본체를
담당하면 데이터 규모가 산출물 부피를 결정하지 않게 된다. 약점이 해소된다.

## 결론 — 1순위를 신유량조절기로 교체

**[대전] 건양대학교의료원 신유량조절기 수액치료 데이터**

세 제약이 모두 같은 방향을 가리킨다.

| 제약 | 신유량조절기의 대응 |
|---|---|
| 데이터 실물 못 봄 | 설명서에 인자·수준·8군·23컬럼이 명시 → 제안서를 확정 스펙 위에 쓸 수 있다 (미기재 항목은 방문 1단계 확인으로 고정) |
| 방문 1회 4시간 | 120행 표. 완주 확실, 재분석 여유, 반출 심의도 집계 통계라 통과 쉬움 |
| RAG 형식 | 오차 예측 수치 + 근거 문서 검색의 결합이 자연스럽고, 규모 약점을 상쇄 |

추가 이점: 참신성 30점에서 **진짜 미개방 + 아무도 다루지 않은 주제**라는 위치가
CAC보다 오히려 낫다. CAC는 선행연구가 두껍고 상용 제품까지 나와 있어서
"이미 있잖아요"를 방어하는 데 제안서 2장을 써야 했다.

## 포기하는 것 (정직하게 계산)

| 항목 | 손실 | 보완 |
|---|---|---|
| 예선 방문 가점 | **−5점 / 100점.** 15팀 커트라인에서 아픈 숫자 | 제안서 완성도로 이겨야 한다. 이게 유일한 답 |
| 본선 방문 횟수 | 1회 = 2점 (7회 만점 10점 대비 −8점) | 수행 30점 중 나머지 20점(도구·데이터 활용 10, 규정 5, 태도 5)과 발표 70점에 집중 |
| CAC 제안서 작업분 | 선행연구 조사는 폐기 | [선행연구 지형](02-선행연구-지형.md)은 보존. 방문 여건이 바뀌면 복귀 가능 |

**규정 확인: 안심존 미방문 시 탈락 가능 → 본선 1회 방문으로 이 조건은 충족한다.**
