## 핵심 발견 요약

**절대 잊으면 안 되는 것 — 주관기관이 이 데이터로 이미 논문을 냈다.**
Choi JG et al., *Med Devices (Auckl)* 2025;18, doi:10.2147/MDER.S495996. 건양대병원,
암환자 59명·100회, 수집 2023.10~2024.01(**우리 데이터 기간을 포함**), 평균 오차율 4.75%.
→ 정확도 재측정은 전면 중복. 그 논문이 남긴 **6개 공백**에 앉혀야 한다 (06번 문서)

1. 설명서가 이미 **"오차율 평균 ±10% 이내"**라고 밝혔다 → "오차가 크다" 프레이밍 금지.
   질문은 **"±10%가 그 약물에 허용되는가"**로 옮긴다
2. **약물명이 심하게 오염**되어 있다 (22개 문자열 = 12개 성분, `Perbrolizumab` 등)
   → LLM 정규화가 장식이 아니라 조회의 전제 조건. **참신성 최강 카드**
3. **부작용은 함정.** 서술부엔 3번 등장하지만 23개 컬럼에 없고 "제외기준으로 최소화"됨 → 설계에서 배제
4. **Gemini API 약관이 임상 사용을 명문 금지** → "연구·교육용 근거 탐색 프로토타입"으로 재정의.
   그리고 `gemini-2.5-flash-lite`는 **2026-10-16 퇴역**(본선 마감 전) → `gemini-3.1-flash-lite`로 전환
5. **"측정값 → 검색 → 판정" 패턴은 참신하지 않다** (FHIR-RAG-MEDS 등) → 주장 범위를 좁혀야 한다
6. between-subject 배정 → 군간 공변량 균형 확인이 분석 1단계
7. 담당자 이메일이 대회정보의 602626과 달리 설명서엔 **602625**@kyuh.ac.kr

## 환경 메모 (재작업 시 필수)

- **이 환경엔 pip·PyMuPDF·poppler가 전부 없다.** `python3 -m pip`도 없음 (Python 3.14.4)
- 설명서 일부는 텍스트가 전부 이미지로 렌더된 PDF → 텍스트 추출 불가.
  **zlib만으로 PDF 오브젝트를 파싱해 페이지를 합성하는 렌더러를 작성해 판독했다.**
  스크립트는 세션 스크래치패드의 `render.py` (인자: PDF경로, 출력프리픽스, 배율).
  재현이 필요하면 이 방식을 다시 쓸 것 — 외부 의존성 없이 동작한다
- zip 파일명이 macOS NFD → `unicodedata.normalize('NFC', name.encode('cp437').decode('utf-8'))`. `unzip` 미설치
- daker.ai는 SPA. API 직접 호출: `curl -sL "https://daker.ai/api/hackathons/2026-k-health-unreleased-data-utilization-competit"`
